# QuickDock

QuickDock 是一个 Windows 桌面工具，用于管理、搜索和打开网页、应用、文件与文件夹，同时提供自动鼠标、截图贴图和自动滚动长截图。

## 运行

需要 Windows、Python 3.12 和 PySide6。安装 PySide6-Essentials 后运行 `pythonw main.pyw`；`启动.vbs` 使用当前用户默认位置的 Python 3.12。离线拼音搜索依赖已包含在 `vendor/`。

软件设置和用户入口保存在运行目录；个人快捷入口、图标和文件不包含在此仓库。自动鼠标、截图贴图和长截图记住上次启用状态，自动鼠标不会在启动时自动开始点击。

更多操作说明见 [使用说明](使用说明.md)。打包脚本和依赖说明见 [packaging/README.md](packaging/README.md)。长截图在不同软件和多屏缩放环境下仍可能受到滚动响应与动态内容影响，请检查结果。
