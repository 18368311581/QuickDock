QuickDock 使用说明

快捷入口 · 自动鼠标 · 截图贴图

把常用网页、软件、文件和文件夹放在一起，通过搜索或键盘快速打开。

01　打开与收起

点击屏幕右上角的小窗，展开或收起主窗口。小窗固定置顶，仅左下角为圆角，其余三个角为方角，中间显示软件图标，可以直接点击屏幕最右上方。每次展开都会进入“快捷入口”。

右键小窗或托盘图标，使用同一个菜单：显示桌面小窗、设置、使用说明、退出软件。隐藏小窗会同时收起主窗口；软件仍在托盘运行，可以通过快捷键唤出。

02　键盘快速操作

Ctrl + Alt + Q　全局展开／收起快捷入口。展开时聚焦搜索栏并全选已有文字，直接输入即可开始新搜索；再次按下收起大窗口，保留桌面小窗。

Tab　主窗口内回到快捷入口的搜索栏。添加、编辑等弹窗里仍按正常顺序切换输入框。

↑ / ↓　搜索栏内选择上一条或下一条。
Enter　打开当前选中入口。
Esc　松开按键后收起主窗口，避免剩余按键事件落到后方窗口。

支持中文名称的全拼和首字母搜索，例如“自动鼠标”可输入 zidongshubiao 或 zdsb；拼音不区分大小写，可带空格或分隔符，完全离线转换。多音字按词组常见读音匹配。
搜索按名称、简介和地址的相似度实时排序，第一条自动选中；清空搜索后按名称排序。添加、编辑和删除后的列表刷新会保留滚动位置。

03　添加与编辑入口

点击底部的大号 ＋，或者拖入文件、文件夹、软件快捷方式或网页链接。整个添加窗口都可以接收拖入的内容，程序会尽量识别名称、地址和图标。

名称用于列表显示和搜索，地址决定打开什么，简介用于补充说明。图标可自动获取，也可选择内置图案或本地图片。文件和文件夹选择窗口默认从 QuickDock 所在目录打开。

“高级选项”中的程序参数、工作目录仅在特殊启动方式下使用，普通入口可以留空。删除前会确认，只移除入口，不删除原文件。

04　相对路径与指定浏览器

程序文件夹内的内容可以用相对地址，例如 doc/笔记.txt。把文件放在 QuickDock/doc 后添加，内部路径会转换为相对路径；移动整个 QuickDock 文件夹后仍可使用。外部文件的绝对路径依赖原位置，Windows 快捷方式内部的地址也不会自动改写。

需要指定 Chrome 时，把地址设为 Chrome 的程序路径，在高级选项的“程序参数”中填写带引号的网址。直接填写网址则使用系统默认浏览器。

05　软件设置

右键小窗或托盘 → 设置…，可修改全局唤出快捷键、大窗口不透明度、界面大小和小窗显示状态。界面大小支持 75%～150%，同步调整文字、按钮、行高和间距，默认 100%；保存后立即生效并记住选择。桌面小窗和贴图内容保持原尺寸。屏幕较小时主窗口自动限制宽高，通过滚动查看列表；设置、添加、编辑和图标选择的内容放不下时也可滚动，底部操作按钮保持可见。分辨率、显示缩放或主屏变化后自动重新适配。不透明度使用滑块调节，右侧显示百分比。使用说明在独立窗口中阅读。点击保存后生效，点击取消放弃修改。

不透明度越低，透出的桌面越明显；只影响主窗口，贴图保持不透明。快捷键可以选择“无”来关闭；如果组合键被占用，请换一个。自动鼠标与截图贴图的热键在各自页面独立设置。

在软件设置 → 开机启动中勾选或取消，点击保存后应用；取消设置窗口不会修改启动项。该开关仅对当前用户生效，不需要管理员权限。也可以在 Windows 任务管理器 → 启动应用 → QuickDock中禁用已启用的入口；再次打开软件设置会读取实际状态。退出软件请使用右键菜单中的“退出软件”。

06　自动鼠标

记住上次启用状态，首次使用默认关闭。勾选启用自动鼠标后，选择左键、右键或中键的连点／长按模式，设置次数或持续时间与间隔，再使用开始按钮或页面指定的热键。

运行时使用鼠标当前位置，不自动移动。停止或关闭功能会中断任务并释放按键。模式、数值和热键会保存，启用状态和运行状态不跨启动保留。

07　截图贴图

记住上次启用状态，首次使用默认关闭。勾选启用截图贴图后，可以区域截图、粘贴剪贴板图片、选择图片文件，或者拖入图片。

默认截图热键为 Ctrl + Alt + S。截图时拖出矩形区域，松开生成置顶贴图；按 Esc 或右键取消。

贴图内部拖动可移动；四角等比缩放，四边独立拉伸。双击恢复原始比例，滚轮不缩放。右键贴图可以复制、另存为 PNG、恢复比例或关闭。

列表中的“显示”会将对应贴图提到前面，不移动位置。“暂时隐藏全部贴图”会隐藏图片，再取消即可恢复。关闭截图贴图功能会隐藏现有贴图，重新开启可以继续使用。

图片仅保存在内存中。退出软件后贴图关闭，需要长期保留请先另存为图片。

08　数据与迁移

快捷入口和设置保存在程序目录的 shortcuts.json，图标在 icons，程序图标在 assets。迁移时复制整个 QuickDock 文件夹，并重新检查开机启动快捷方式。

软件只允许一个实例。再次启动时会唤出现有窗口。软件默认以普通用户权限运行。

长截图

在独立的「长截图」页面启用功能（记住上次启用状态，首次使用默认关闭），设置热键和保存目录。框选单个屏幕内的滚动区域后，程序自动向下滚动并拼接；控制条可提前完成并保存或取消。PNG 默认保存在图片文件夹下的「QuickDock 长截图」。请选择不含固定标题栏、悬浮工具栏和动态内容的区域，并检查最终结果。
